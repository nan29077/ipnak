# 입낚 YOLO 학습 데이터

AI 카메라(물고기 · 입낚볼 · 입낚키링 자동 감지) 학습에 쓰는 이미지와 라벨을 모아두는 폴더입니다.
서비스 이미지(`public/uploads`)와 **분리**해 관리합니다.

관리자 화면에서 대부분의 작업을 수행할 수 있습니다:
**관리자 → AI 학습 관리**

---

## 폴더 용도

| 폴더 | 용도 | git 추적 |
|---|---|---|
| `raw/` | 수집된 **원본 이미지**. iNaturalist 자동 수집 + 유저 피드에서 선별한 사진이 여기에 저장됩니다. | ❌ 제외 |
| `labeled/` | 라벨링을 마친 이미지 사본 (내보내기 패키지 구성용). | ❌ 제외 |
| `labels/` | YOLO 포맷 `.txt` 라벨 파일. 이미지 파일명과 1:1로 대응합니다. | ✅ 포함 |
| `exports/` | 학습용으로 내보낸 zip 패키지. | ✅ 포함(생성물은 커밋하지 않음) |

이미지 파일은 용량이 커서 저장소가 비대해지므로 `.gitignore` 에서 `raw/` 와 `labeled/` 를 제외했습니다.
**라벨(`labels/`)은 사람이 만든 자산이므로 git 으로 추적합니다.**

---

## YOLO 라벨 포맷

`labels/<이미지파일명>.txt` — 한 줄이 박스 하나입니다.

```
<class_id> <center_x> <center_y> <width> <height>
```

- 모든 좌표는 이미지 크기로 나눈 **0~1 정규화 값**입니다.
- `center_x`, `center_y` 는 박스 **중심점**입니다 (좌상단이 아닙니다).

예시:

```
0 0.482310 0.551020 0.640000 0.220000
1 0.212500 0.480000 0.070000 0.093000
```

## 작업 흐름

```
1. 수집     관리자 → AI 학습 관리 → 데이터 수집   (iNaturalist 자동 수집)
            관리자 → AI 학습 관리 → 피드 사진 선별 (유저 사진 선별)
                ↓  raw/
2. 라벨링   관리자 → AI 학습 관리 → 라벨링
              · 옵션 A: Roboflow 로 업로드해 전문 툴에서 작업
              · 옵션 B: 입낚 관리자 캔버스에서 직접 박스 그리기
                ↓  labels/
3. 내보내기 라벨링 탭 → "YOLO 학습셋 내보내기" → zip 다운로드
                ↓  exports/
4. 학습     train_yolov8.ipynb 을 Google Colab 에 업로드해 실행
                ↓  best.onnx
5. 배포     관리자 → AI 학습 관리 → 모델 관리 → 새 모델 업로드
                ↓  public/models/best.onnx  →  AI 카메라에 즉시 적용
```
